# Security

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/protocol/neuro-atlas/security/advisories/new). Private reporting is enabled for this repository.

Do **not** disclose exploit details, credentials, personal information, or private visitor feedback in public issues or pull requests. Include affected routes/revisions, reproduction steps, and impact in the private report. Use synthetic examples rather than real personal records.

We maintain the current `main` branch and deployed Neuro Atlas application; there are no separately maintained versioned release lines. Maintainers will triage reports privately. This policy does not promise a response time or bug bounty.
