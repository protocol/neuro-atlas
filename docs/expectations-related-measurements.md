## Boundaries

- The full signals remain authoritative, including the alternative funding branch for distillation and the acquisition condition for the energy pivot. No scientific JSON, observed values, thresholds, extrapolation logic or authentication configuration changes.
- The last link targets the existing fidelity panel rather than its enclosing family; it is the same reviewed evidence, not a new measurement.
- Existing external forecast question texts/URLs remain in a separate, collapsed **Related forecasts** disclosure. Stored market commentary is not presented as a current price. No empty forecast or WIP cards are shown.
- Idea vintage, latency compression and Google Trends remain field context. Additional bottleneck links and direct outcome tracking are outside this small change.

## Navigation contract

The href is an ordinary same-page fragment, preserving origin, deployment base path and query. Unmodified activation uses the existing Metrics navigation path, which switches tabs, clears stale search, opens the category and scrolls to the real target. Modified clicks retain browser defaults. The new link origin retains keyboard focus through Back/Forward; fresh direct links keep existing Metrics behavior. Focus waits for the hidden category to reveal and cancels on navigation/unmount.

Regression coverage: `tests/expectations-related-measurements.test.mjs`. Native verification and exact revision evidence are recorded with the PR, separately from any hosted release claim.
