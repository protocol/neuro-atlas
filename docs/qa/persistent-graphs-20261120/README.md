## Deliberate first-PR limits

Dashboards save in the current browser; copied links carry validated layout/settings, not an encrypted record, frozen future dataset or account-synced workspace. Per-card dashboard images and unsupported filtered/scenario PNGs remain unavailable with a visible explanation; use the dashboard link. Anatomical/image-capacity/budget scenarios retain their metric-specific assumptions, and no universal auditory or mammalian completion target is invented. Extrapolation is supplied only where the eligible-series model is defensible.

Web Locks serialize cooperating updated tabs; fallback read/check/write is not universally atomic against older/noncooperating writers. Draft retention across link changes applies while the dashboard stays mounted; save/copy explicitly before reload, close or route replacement. Hosted proxy/authenticated deployment behavior remains unverified because deployment is expressly prohibited. No merge or release approval is inferred from these local results.
