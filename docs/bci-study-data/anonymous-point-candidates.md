# Four anonymous BCI marks — useful candidates, not proven assignments

**There are credible paper leads for all four marks.** The best working mapping is **Gilja 2015 (with Jarosiewicz 2015 an equally plausible alternative), Bacher 2015, Vansteensel 2016, and Milekovic/Sarma 2018**. None is a proven identification of Sumner Norman's anonymous points.

The existing approximately **0.90 / 0.76 / 0.16 / 0.53 bps** values come from the photographed slide. I inspected the [original chart image](https://pbs.twimg.com/media/HLc_CpXaIAA-nFr?format=jpg&name=orig) and measured its four anonymous blue circles directly: approximately **0.93 / 0.79 / 0.16 / 0.55 bps**. These remain visual digitizations, not printed measurements. The small difference matters when judging candidate numerical matches. `original-image-blue-component-check.json` retains the pixel centers, independently detected axis tick rows, logarithmic calibration, and result.

## Conversion boundary

Converting typing into bytes is fair **if the convention is explicit**. One byte/character means `characters/min × 8/60` encoded bits/s. That is not interchangeable with BCI information transfer rate or Fitts throughput. A uniform-symbol coding equivalent instead uses `characters/min × log2(alphabet_size)/60`. Neither alphabet size nor English entropy can be recovered from the plotted height alone.

For comparison above, the 28-symbol convention is the **same illustrative analyst assumption**, not a discovered chart method or actual interface target count. Native correct-character rates already charge error-correction time; no extra accuracy multiplier was applied. Prediction/completion conditions are retained. Numerical proximity is a lead, not identity evidence.
